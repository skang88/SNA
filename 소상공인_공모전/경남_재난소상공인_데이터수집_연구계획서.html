3. 실전 데이터 병합(Merge) 및 분석 파이썬 스크립트

다운로드받은 행안부 재해통계와 소진공 상가정보 및 MDIS 실태조사를 경남 시·군 코드(`sigungu_cd`)를 기준으로 1:1 결합하는 파이프라인 코드입니다.

# 1. 라이브러리 로드 import pandas as pd import statsmodels.api as sm import statsmodels.formula.api as smf # 2. 데이터 불러오기 disaster_df = pd.read_csv("경남_시군별_재난피해_2020_2024.csv") # 행안부 재해연보 semas_fund_df = pd.read_csv("경남_재해긴급경영자금_집행현황.csv") # 소진공 정책자금 survey_df = pd.read_csv("mdis_소상공인실태조사_경남.csv") # MDIS 마이크로데이터 # 3. 경남 시군 단위 병합 (Key: sigungu_cd) merged_df = pd.merge(survey_df, disaster_df, on="sigungu_cd", how="left") merged_df = pd.merge(merged_df, semas_fund_df, on="sigungu_cd", how="left") # 4. Chapter 9 확장 로지스틱 회귀분석 실행 (가설 검정) # 종속변수: 폐업 고려 여부(close_down_intent: 1/0) 또는 가족대출 의존 여부(family_loan: 1/0) model = smf.logit( "close_down_intent ~ disaster_damage + elderly_owner + tenant_business + semas_fund_received + (disaster_damage * semas_fund_received)", data=merged_df ).fit() # 5. 결과 요약 출력 (Table 9.3 형식) print(model.summary())
모델 상호작용항 `(disaster_damage * semas_fund_received)`의 의미
재난 피해(`disaster_damage`)가 커질수록 소상공인의 폐업 및 가족 대출 전락 확률이 급증하지만, 소진공의 재해 정책자금(`semas_fund_received`)을 지원받은 경우 이 기울기가 완만하게 꺾이는 상호작용 완충 효과(Negative Interaction Term, $p < 0.05$)를 입증할 수 있습니다.

4. 경남도청 및 소상공인시장진흥공단 맞춤 정책 제언

1. '재해확인증' 발급 시효 완화 및 디지털화
현행 지자체 재해 확인 신청 기한(10일 이내)은 경황이 없는 이재민에게 너무 촉박합니다. 소방·지자체 현장 출동 DB와 연계하여 자동 발급하는 '원스톱 패스트트랙' 도입을 제안합니다.
2. '가족 부재' 고립 영세상인 핀셋 대환대출
Chapter 9 분석처럼 노인·1인 소상공인은 가족 금융망이 없습니다. 이들에게 신용보증 문턱을 낮추고 순수 공적 재해긴급자금(2.0% 이하)을 100% 직접대출로 지원하는 안전망 확충이 시급합니다.
